# 北京专精特新企业商会复盘 Skill

用于全面复盘北京专精特新企业商会（公众号 bjzjtx001）的内容运营、会员调研、外部市场情报，最终产出**目标会员画像**与**需求热度排序**两份核心交付物，支撑商会的会员增长与服务设计决策。

---

## 适用范围

- 公众号内容运营复盘（阅读、转发、留言、收藏、关注转化）
- 现有会员调研（问卷 + 1对1深访）
- 北京市专精特新企业名单（约6000家）的行业/规模/区域分层
- 输出可执行的会员增长策略与服务产品优先级

## 工作流程

按以下 4 个阶段顺序推进。每个阶段开始前先用 TodoWrite 写出子任务清单，每完成一项立即标记完成。

### 阶段 1：公众号数据分析

**目标**：识别哪类内容最能驱动阅读、转发、关注转化，建立"内容-需求"对应表。

**所需数据**（向用户索取或从公众号后台导出）：
- 近 6–12 个月所有推文的：标题、发布时间、阅读量、在看、转发、收藏、留言数、新增关注数（如有）
- 推文类别打标（建议初始 6 类）：
  1. 政策解读（国家级/北京市/区级专精特新政策）
  2. 政策申报辅导（小巨人申报、专项资金、研发费用加计扣除等）
  3. 融资案例 / 资本对接
  4. 供需对接 / 产业链协作
  5. 商会活动 / 会员风采
  6. 行业趋势 / 标杆研究

**分析维度**：
- 阅读量 Top10 / Bottom10 推文的类别分布
- 单篇平均阅读量按类别排序
- 转发率（转发÷阅读）、在看率、收藏率分类对比 → 揭示"传播力" vs "工具价值"
- 关注转化效率（如有外链或活码数据）
- 标题关键词词频（如"申报""补贴""对接""路演"等触发词）
- 发布时间 / 频次与表现的相关性

**输出**：`outputs/01-content-analysis.md`，含 Top 类别排序、典型爆款拆解、内容选题建议。

参考模板：`templates/data-analysis-framework.md`

### 阶段 2：现有会员调研

**目标**：还原"入会动机 → 实际使用 → 续费意愿 → 未满足需求"的完整链路。

**两条并行路径**：

**A. 问卷调研**（覆盖面，目标回收 ≥ 30% 会员）
- 使用 `templates/member-survey.md`，建议通过腾讯问卷/金数据投放，公众号菜单+群内+小程序多渠道
- 核心追问：入会动机（多选+排序）、过去 6 个月使用过哪些服务、满意度（NPS）、最希望新增什么服务、愿意付费的服务及价格区间

**B. 深度访谈**（深度，目标 8–15 人）
- 使用 `templates/member-interview-guide.md`，每场 30–45 分钟
- 受访人结构建议：
  - 高活跃会员 3–5 人（参加过 ≥3 次活动）
  - 沉默会员 3–5 人（入会后基本不参与）
  - 已流失/未续费 2–3 人（最关键，揭示价值断点）
  - 不同行业 / 区域 / 规模交叉覆盖

**输出**：`outputs/02-member-research.md`，含动机词云、需求频次排序、典型用户故事 3–5 个、续费驱动因子、价值断点清单。

### 阶段 3：外部情报 — 6000 家专精特新企业分层

**目标**：在全量名单中识别"高潜力 + 易触达 + 强需求"的目标入会企业，建立打单优先级。

**数据源**：
- 北京市经信局公示的专精特新中小企业名单（市级+小巨人）
- 工信部国家级专精特新"小巨人"名单（北京部分）
- 企业工商信息（启信宝/天眼查 API 或人工补充）补齐：成立年限、注册资本、社保人数、融资轮次、所属街道/园区

**三维分层**：

| 维度 | 分层建议 |
|---|---|
| **行业** | 新一代信息技术 / 高端装备 / 新材料 / 生物医药 / 新能源 / 节能环保 / 数字创意 / 其他（按北京市重点产业图谱对齐） |
| **规模** | 微型(<20人) / 小型(20–100) / 中型(100–500) / 中大(500+)；按营收 0–2000万 / 2000万–1亿 / 1亿–4亿 / 4亿+ 交叉 |
| **区域** | 海淀(中关村) / 朝阳 / 经开区 / 昌平 / 大兴 / 顺义 / 石景山 / 丰台 / 通州 / 房山 / 其他；并标注所属重点园区 |

**优先级评分**（每维度 1–5 分，加权汇总）：
- 行业匹配度（与商会会员现有产业生态契合度）× 0.3
- 规模匹配度（中型企业通常付费意愿最强）× 0.25
- 区域可达性（线下活动半径）× 0.15
- 新晋认定（近 12 个月新认定，处于政策红利期，入会动机强）× 0.2
- 现有会员关系链覆盖（可被现有会员转介绍）× 0.1

**输出**：`outputs/03-external-segmentation.md` + 一张分层表格（CSV/表格形式），标注 Top 500 优先触达名单。

参考模板：`templates/enterprise-segmentation.md`

### 阶段 4：综合输出

整合阶段 1–3 的结论，产出两份核心交付物：

#### 交付物 A：目标会员画像
位置：`outputs/target-member-persona.md`

包含字段：
- **企业属性**：行业、营收区间、员工规模、成立年限、所在区/园区、认定级别（市级/小巨人）、融资阶段
- **决策角色**：决策人职位（董事长/总经理/政府事务负责人/财务总监）、关注议题、信息获取渠道
- **痛点 Top5**：基于阶段 2 调研提炼
- **付费能力与意愿**：年会费可承受区间、增值服务付费偏好
- **触达路径**：最有效的拉新动作（政策直播 / 申报辅导沙龙 / 园区合作 / 老会员转介绍）
- **画像分层**：建议输出 2–3 个子画像（如"成长型小巨人 CEO""政策驱动型创始人""产业链整合型中型企业 GR 负责人"）

#### 交付物 B：需求热度排序
位置：`outputs/needs-ranking.md`

格式建议：

| 排名 | 需求 | 调研频次 | 内容数据印证 | 付费意愿 | 商会当前供给 | 缺口 | 行动优先级 |
|---|---|---|---|---|---|---|---|
| 1 | 政策申报辅导 | 78% | 政策解读类阅读 Top1 | 高 | 弱 | 大 | P0 |
| 2 | 产业链对接 | 65% | 供需类转发率最高 | 中 | 中 | 中 | P0 |
| 3 | 融资服务 | 52% | 融资案例阅读高但转发低 | 中高 | 弱 | 大 | P1 |
| 4 | 品牌曝光 | 40% | 会员风采阅读偏低 | 中 | 强 | 小 | P2 |
| ... | ... | ... | ... | ... | ... | ... | ... |

排序逻辑：综合"调研频次（40%）+ 内容数据印证（25%）+ 付费意愿（25%）+ 缺口大小（10%）"加权。

## 启动时需向用户索取的信息（清单）

调用本 skill 时，先用 AskUserQuestion 确认以下输入是否齐备。缺哪项就先问哪项，不要凭空假设。

1. 公众号后台数据导出（CSV/Excel，近 6–12 个月）
2. 现有会员名单（脱敏即可，含行业/规模/入会时长）
3. 是否已有问卷渠道与触达通道（用于阶段 2）
4. 北京市专精特新名单是否已下载，或需要协助梳理来源
5. 商会现有服务清单与定价（用于交付物 B 的"当前供给"列）
6. 时间预算（紧迫程度决定是否走访谈/只做问卷）

## 完成本 skill 后，可能仍需用户提供的协助

主动告诉用户以下事项可能需要他/她出面或决策：

- **公众号后台权限**：阅读/转发等数据需运营员导出
- **会员触达背书**：问卷与访谈邀请用商会会长/秘书长名义发出回收率会高 3–5 倍
- **企业工商数据**：6000 家企业的融资/规模数据如需补齐，需启信宝/天眼查 API 或采购名录
- **访谈对象指定**：流失会员名单较敏感，需会长授权
- **结果落地资源**：交付物给出策略后，是否有预算/人员落地新服务（如政策申报辅导组、产业对接专员）
- **隐私合规**：会员调研涉及个人信息，需确认告知同意条款

## 交付节奏建议

| 阶段 | 工时 | 关键里程碑 |
|---|---|---|
| 阶段 1 | 2–3 天 | 内容分析报告初稿 |
| 阶段 2 | 5–10 天 | 问卷回收 + 访谈完成 |
| 阶段 3 | 3–5 天 | 6000 家分层表 + Top500 名单 |
| 阶段 4 | 1–2 天 | 两份核心交付物定稿 |

总计约 2–3 周。如时间紧，可先并行启动阶段 1 + 阶段 3，阶段 2 因依赖回收周期最长，应最先发问卷。
