# 目标会员画像（输出模板）

> 本文档为输出模板，阶段 1–3 完成后填充实际数据。

## 总览：3 个核心子画像

| 画像 | 占比 | 年付费意愿 | 优先级 |
|---|---|---|---|
| A. 成长型小巨人 CEO | 约 40% | 2–10 万 | P0 |
| B. 政策驱动型创始人 | 约 35% | 5000–3 万 | P0 |
| C. 产业链整合型 GR/总助 | 约 25% | 1–8 万 | P1 |

---

## 画像 A：成长型小巨人 CEO

**典型企业属性**
- 行业：新一代信息技术 / 高端装备 / 新材料
- 营收：1 亿–4 亿
- 员工：100–300
- 成立年限：8–15 年
- 区域：海淀（中关村）/ 经开区 / 昌平
- 认定：国家级小巨人，部分进入重点小巨人
- 融资阶段：B–C 轮，或已申报北交所/科创板

**决策角色画像**
- 职位：董事长 / CEO，70 后为主，一线技术出身
- 关注议题：上市辅导、产业链订单、人才落户、海外拓展
- 信息渠道：公众号深度文章、行业峰会、政府主管部门
- 决策风格：信任专业背书，关注 ROI，反感泛社交

**Top 5 痛点**
1. （示例）申报国家级专项资金缺辅导，自己写没胜算
2. 想上市但不熟悉北交所/科创板规则
3. 上下游订单依赖 1–2 家大客户，需要多元化
4. 核心研发人才招聘难
5. 海外业务合规与渠道

**付费偏好**
- 年会费：2–5 万可接受
- 增值服务：政策申报成功分成（5–10%）、IPO 辅导陪跑（10 万+）
- 拒付：泛培训、纯社交活动

**触达路径优先级**
1. 主管部门 / 区经信委推荐（信任度最高）
2. 已是会员的同行 CEO 转介绍
3. 上市/政策深度公众号文章
4. 政府主办活动现场

---

## 画像 B：政策驱动型创始人

**典型企业属性**
- 行业：跨行业，新认定企业为主
- 营收：2000 万–1 亿
- 员工：30–100
- 成立年限：3–8 年
- 区域：朝阳 / 大兴 / 顺义 / 通州
- 认定：近 12 个月新认定的市级专精特新或小巨人

**决策角色**
- 职位：创始人 / 总经理，80 后为主
- 关注议题：能拿到的现金补贴、研发费用加计扣除、税收优惠
- 信息渠道：公众号活码、企业服务群、园区运营方推荐

**Top 5 痛点**
1. 申报材料不会写，不知道哪些补贴能拿
2. 区级、市级、国家级政策叠加规则混乱
3. 缺融资渠道
4. 财税合规风险
5. 找不到对的供应商/客户

**付费偏好**
- 年会费：5000–1 万为主，2 万为上限
- 高意愿付费项：政策申报代办、财税顾问包年
- 价格敏感

**触达路径**
1. 园区运营方联合推广
2. 公众号"申报清单"类爆款拉新
3. 财税合作机构白名单导流
4. 区主管部门活动现场

---

## 画像 C：产业链整合型 GR / 总助

**典型企业属性**
- 行业：高端装备 / 新能源 / 生物医药
- 营收：4 亿+
- 员工：500+
- 区域：经开区 / 海淀 / 昌平生命科学园
- 已是行业头部，部分上市公司

**决策角色**
- 职位：政府事务总监 / 总裁办主任 / 副总
- 关注议题：行业话语权、政策建言渠道、上下游产业整合、招商
- 信息渠道：政府闭门会、行业协会、领导出席的活动

**Top 5 痛点**
1. 想参与政策制定但缺渠道
2. 寻找产业链上的潜在被收购标的
3. 帮老板维护重要政府关系
4. 行业标准制定话语权
5. 人才与高端论坛资源

**付费偏好**
- 年会费：可接受 5–10 万的高端理事会费
- 看重：与会长/秘书长的直接接触、闭门活动、政策直通车

**触达路径**
1. 会长/秘书长亲自拜访
2. 政府闭门会同框
3. 行业头部企业互推

---

## 共性结论

- **核心目标人群**是画像 A + B 的重叠区：营收 5000 万–2 亿、员工 50–300、近 24 个月新认定的中型企业
- **首要触达地理**：海淀、经开区、朝阳，覆盖约 60% 高潜力企业
- **首要触达节点**：每年市经信局公布新一批名单后 30 天内，是入会动机最高峰
