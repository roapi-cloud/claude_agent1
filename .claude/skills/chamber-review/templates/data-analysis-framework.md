| 字段 | 必需 | 说明 |
|---|---|---|
| 推文标题 | ✓ | |

| 留言数 | ✓ | |

| 阅读完成率 | 可选 | |
| 标题字数 | 自动 | |
| 头图类型 | 可选 | 政策红头文件 / 人物 / 数据图 / 活动现场 |

## 关键指标定义

- **传播系数** = 转发数 ÷ 阅读量（>3% 算高）
- **工具价值** = 收藏数 ÷ 阅读量（政策类 >5% 说明会员当工具书）
- **互动深度** = 留言数 ÷ 阅读量
- **拉新效率** = 新增关注 ÷ 阅读量

## 爆款拆解模板（取 Top5）

每篇填写：
- 标题 + 链接
- 类别
- 阅读量 / 转发 / 收藏
- 选题角度（"政策时效性"/"具体金额"/"名单"/"避坑"等）
- 头图与排版特征
- 可复制的元素 3 条
