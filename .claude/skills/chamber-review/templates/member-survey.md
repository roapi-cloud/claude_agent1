# 会员问卷模板（建议 5–7 分钟可完成）

> 投放渠道：公众号菜单"会员中心" + 会员群 + 1对1企微推送
> 激励：完成问卷送《2026 北京专精特新政策汇编 PDF》或抽奖
> 平台：腾讯问卷 / 金数据 / 问卷星

---

## 一、企业基本信息（5 题）

1. 贵公司所属行业（单选，对齐北京市重点产业目录）
2. 贵公司年营收区间：[<2000万 / 2000万–1亿 / 1亿–4亿 / 4亿+]
3. 员工规模：[<20 / 20–100 / 100–500 / 500+]
4. 所在区域 / 园区
5. 已获得的认定级别：[区级 / 市级专精特新 / 国家级小巨人 / 重点小巨人]

## 二、入会动机（核心，4 题）

6. 您当初加入商会的主要原因是？（多选，最多 3 项，并请按重要性 1–3 排序）
   - A. 获取最新政策信息
   - B. 申报政府项目获得辅导
   - C. 对接产业链上下游客户/供应商
   - D. 寻找投资机构 / 融资
   - E. 结识其他企业家 / 拓展人脉
   - F. 提升企业品牌曝光
   - G. 享受商会团购 / 法律 / 财税等增值服务
   - H. 政府关系 / 行业话语权
   - I. 其他：______

7. 入会前对商会最大的期待是什么？（开放题，1 句话）

8. 入会前是否同时考虑过其他商会/协会？为什么最终选择我们？

9. 当初是通过什么渠道知道商会的？
   [公众号 / 朋友推荐 / 政府活动 / 园区推荐 / 主管部门 / 其他]

## 三、过去 6 个月使用情况（5 题）

10. 您参加过商会哪些活动/服务？（多选）

12. 哪项服务对您价值最大？为什么？
13. 哪项服务您参加过但觉得"不解渴"？
14. 过去 6 个月，您与商会的接触频次：[每周 / 每月 / 每季度 / 几乎没有]

## 四、未来需求（核心，4 题）

15. 未来 12 个月，您最希望商会新增/加强哪些服务？（多选最多 5 项 + 排序）
   - 政策申报全程辅导（含撰写 / 答辩陪跑）

   - 政府关系 / 政策建言渠道
   - 媒体曝光 / 品牌打造
   - 数字化转型咨询
   - 其他：______

16. 上述需求中，您愿意付费购买的有哪些？分别能接受的年费区间？
   （0–5000 / 5000–2万 / 2万–10万 / 10万+）

## 数据分析输出口径

- 第 6/15 题做"动机词云 + Top10 排序"
- 第 11 题计算 NPS = 推荐者(9–10)% − 贬损者(0–6)%
- 第 16 题计算每项服务的"加权付费意愿指数"= 选择人数 × 平均价格区间中位数
- 第 19/20 题做流失漏斗，识别"价值断点"
- 交叉分析：行业 × 需求 / 规模 × 付费意愿 / 入会渠道 × 满意度
